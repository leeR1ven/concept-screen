# 按 concept-brain 架构做"看画面 → 按键"的实测记录

日期：2026-11-05
依据：`leeR1ven/concept-brain` 的 `docs/ARCHITECTURE.md`、`docs/THEORY.md`、`docs/EQUIVALENCE.md`（均已读）。
原则：只用一条局部赫布规则（时序、协方差形式、凹形增长 + 统一降权），**没有反向传播**。

## 一、实现（`experiments/p51_screen2key.py`、`p62_core.py`、`p64_play8.py`、`p65_curriculum.py`）

| 部分 | 做法 |
|---|---|
| 输入 | 8×8 画面 → 每像素 4 级温度计正反对（每像素恰亮 2 格，共 128 格亮 / 512 总） |
| 中间层 | 三层固定随机网络，每个神经元接附近 8 个输入，门槛取自身输入的 70% 分位 |
| 最后一层 | 每拍挑最强 top-m，m = 第一层亮的数量（架构规定） |
| 学习 | 时序赫布，协方差形式（两侧减平时水平），凹形增长 `η·a·b/(1+w/w_ref)^pow` |
| 决策 | 对每个候选动作算最后一层，预测"这一步之后会不会死"，选风险最低的 |

## 二、四个排查（每个都有数字，且前三个曾把我误导）

| 排查 | 结果 | 结论 |
|---|---|---|
| ① 物理可玩性 | 提前 1~2 格起跳存活 **0%→100%**（改跳跃参数后） | **曾经游戏本身跳不过去**；不修就永远"学不会" |
| ② 表示可区分 | 线性探针：8×8 = **1.000**，16×16 = **0.556** | 分辨率**不是越高越好**：最后一层容量固定，坑在 16×16 里只占 12.5%，信息被稀释 |
| ③ 重叠量法 | 含公共背景时 c/o=1.26；去掉公共部分后 **c/o=3.94** | 必须按 `THEORY §2.2` 去掉"什么都亮"的部分再量 |
| ④ 动作空间 | 见下表 | 动作越多越需要"情境门控" |

## 三、动作空间与门控（本轮最关键的结论）

固定 3 个坑的关卡：

| 配置 | 最远 x | 局数 |
|---|---:|---:|
| 2 动作（前进 / 前进+跳） | **3291** | 18 |
| 3 动作（+ 原地跳），无门控 | **33.5** | 187 |
| 3 动作 + 门控 0.5 | 2271 | 78 |
| 4 动作 + 门控 1.0 | 2509 | 17 |
| 不跳（基线） | 5.5 | — |
| 随机按键（基线） | 5.5 | — |
| 脚本"会玩的人" | 301 | — |

**门控**：预测"不危险"时，只允许"往前走"的动作（原地跳、不动被禁止）；预测"危险"时全部放开。
这是架构里"很少一起亮的神经元互相抑制"在执行层的实现。

**结论**：只有一条赫布规则时，动作空间一大就崩（3291 → 33.5）；加门控后 4 个动作也能回到 2500 米级。

## 四、泛化（随机关卡）

坑位每局随机（间隔 10~16 格、宽 2 格）：

| 配置 | 最远 x | 局数 |
|---|---:|---:|
| 2 动作 | 1612 | 95 |
| 4 动作 + 门控 1.0 | **2046** | 93 |

**固定关卡能过可能是背位置；随机关卡也能过，才说明它真的在看画面。**

## 五、凹形增长的作用（真实马里奥数据，2547 帧）

| 键 | 线性增长 | **凹形增长** | 基线 |
|---|---:|---:|---:|
| right | 0.740 | **0.947** | 0.659 |
| A（跳） | 0.222 | **0.555** | 0.815 |
| B（跑） | 0.942 | 0.932 | 0.736 |
| 总体 | 0.659 | **0.747** | 0.862 |

凹形增长（越高越难涨）让稀有键"跳"从 0.222 提到 0.555；但**参数不能太凹**（pow=2 时掉回 0.234）。

## 六、还没做的

- 真实马里奥数据上的闭环（需要先做动作压缩，256 种按键组合按本文结论学不动）；
- 海马体、杏仁核、概念区尚未接入这条闭环（架构里有，本文只验证了"感觉→前额叶→运动"）。

## 七、后续实验与结论（2026-11-05 晚）

### 7.1 长关卡 + 课程学习：通关，但会背关卡

| 关卡 | 课程重开 | 通关率 |
|---|---|---|
| 120 格 | 有（从最远-15 重开） | **60%**（657/1103） |
| 200 格 | 有 | 63% |
| 加 6 个移动敌人 | 有 | 58%（646/1120） |

三类障碍（坑 / 障碍块 / 移动敌人）用同一套危险预测都能过。

### 7.2 关掉课程、每局随机布局：真实泛化只有 6% / 0%

| 训练方式 | 训练通关率 | 没见过的关卡 |
|---|---:|---:|
| 固定布局 + 课程重开 | 49~60% | **0%** |
| 每局随机布局（120 格，三类障碍） | **0%** | 0% |
| Level1（40 格、只有坑、随机布局） | **6%**（852 局） | **0%**（40 局） |

**结论：之前的通关是背关卡，不是学规则。** 随机布局下真实能力 6%，新关卡 0%。

### 7.3 换游戏（接东西，只左右移动）：学不动

| 版本 | 接住率 |
|---|---:|
| 随机基线 | 0.182 |
| 状态→价值 | 0.236 |
| 动作条件价值 | **0.294**（最好） |
| + 稀疏学习 | 0.278 → 15000 步退化 0.176 |
| + 凹形降权 | 0.217 → 15000 步 0.162 |

**训练越久越差**：学到的方向被后续样本冲掉。

### 7.4 动作专用通路：让动作可区分，但导致"连跳"

最后一层加一条固定随机通路 `A·(按键副本)`（6 格按键不再被 128 格视觉淹没）：

| 指标 | 加通路前 | 加通路后 |
|---|---:|---:|
| 风险[不跳] vs 风险[跳] 之差 | **0.0000** | **-0.82**（跳更低） |
| 跳的比例 | — | **0.83**（几乎每拍都跳） |
| 通关率 | 6% | **0%** |

**方向对了但结果更差**：学到"跳安全"后疯狂连跳，到不了坑边。四种标签修正（死亡标注 / 死亡加权 5× / 因果标签 / 四类标签）都没有改变这个结果。

### 7.5 阶段结论（诚实版）

**成立**：架构可搭（温度计编码、局部随机层、top-m、时序赫布、凹形增长、门控、动作通路），四排查数字齐全，固定关卡的通过率 49~60%。

**不成立**：**在随机布局下学出可泛化的通关策略（6% 训练 / 0% 新关卡）**；换到"横向对准"类游戏也学不动（0.29 → 退化）。

**卡点**：单步"argmin 危险"的决策 + 每拍独立决策，导致（a）动作一旦被判安全就被过度使用（连跳），（b）长因果链的价值无法回溯到早期决策。

**下一步建议**：①先用大量真实数据预训练"预测下一帧"（让中间层有特征，符合架构"先看世界"）；②决策改为"预测若干步后的存活"而不是"下一步危险"；③让中间层也可塑（现在只有最后一层→第一层可学）。
